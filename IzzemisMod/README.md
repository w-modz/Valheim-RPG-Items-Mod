# Izzemi's Mod

Author: Izzemi

Adds rarity and damage modifiers to existing Valheim weapons.

## Installation (manual)

Install the package with a compatible Thunderstore mod manager or place the plugin files in `BepInEx/plugins`.

## Features

- Set item rarity on held weapons.
- Add and remove damage modifiers from held weapons (Magic: 1, Rare: 2, Epic: 4).
- Add non-damage effects: reduced stamina cost, reduced movement penalty, improved block armor and parry, backstab damage, and adrenaline on hit.
- Current test values: −10% stamina cost, up to +100 percentage points movement penalty reduction (capped at 0 penalty), +20% block armor, +0.5x parry, +1x backstab, and +1 adrenaline per hit.
- View rarity and modifier details in item tooltips.
- See rarity colors on item tooltips and visuals.
- Preserve rarity and modifiers when upgrading an item through the crafting UI.
