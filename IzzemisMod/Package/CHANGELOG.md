# Changelog

## 1.1.0

### Added
- Runes can now be found in loot chests in the Black Forest, Swamp, Mountains, Plains, Mistlands and Ashlands. Each newly generated chest has a chance to contain a rune matching its biome.
- New world modifier, **Chest Rune Rate** (1x–4x), controlling how many runes appear in newly generated loot chests.
- New world modifier, **Rune Drop Rate** (1x–20x), controlling rune drop chances from normal enemies. Boss drops are unchanged.
- Particle effects on equipped rarity items.
- Sound and visual feedback when a rune drops.
- Hildir now sells runes.

### Changed
- Adjusted rune drop rates for enemies.

## 1.0.0

- Initial release.
